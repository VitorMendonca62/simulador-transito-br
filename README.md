# Simulador de Trânsito BR

Simulador de trânsito no navegador com comportamento brasileiro. Contexto completo, decisões e roadmap em [`docs/CONTEXT.md`](docs/CONTEXT.md).

```bash
npm install
npm run build:core   # requer Rust + wasm-pack
npm run dev
```

Clique em **Importar mapa** (`.osm` ou `.pbf`), ou **Exemplo** para o mapa sintético. Clique num nó laranja para ver as conversões.
