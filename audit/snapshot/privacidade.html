Política de Privacidade

Última atualização: 28 de julho de 2026

1. Quem somos

O MedLogic Pro é um aplicativo voltado exclusivamente para profissionais de saúde, desenvolvido e operado pela Opex Consultoria Ltda (CNPJ: 53.858.521/0001-40), com sede no Brasil. Dúvidas sobre esta política podem ser enviadas para contato@opextecnologia.com.br.

2. Dados que coletamos

Coletamos apenas os dados necessários para o funcionamento do app:

  • Dados de cadastro: nome, sobrenome e endereço de e-mail, informados no momento do registro.
  • Dados de autenticação: token JWT armazenado localmente no dispositivo para manter a sessão ativa.
  • Dados de uso: interações com algoritmos e calculadoras, usados apenas para exibir resultados ao próprio usuário.

Não coletamos dados de pacientes. O app é uma ferramenta de consulta para profissionais, não um prontuário ou sistema de registro clínico.

3. Como usamos os dados

  • Autenticar o usuário e manter a sessão ativa.
  • Personalizar a experiência (nome exibido no perfil).
  • Enviar comunicações essenciais, como redefinição de senha (via e-mail).

Não utilizamos seus dados para publicidade, nem os compartilhamos com terceiros para fins comerciais.

4. Compartilhamento de dados

Seus dados não são vendidos, alugados ou compartilhados com terceiros, exceto nas seguintes situações:

  • Quando exigido por lei ou ordem judicial.
  • Com prestadores de serviço de infraestrutura (ex.: serviços de hospedagem em nuvem) que operam sob acordos de confidencialidade.

5. Armazenamento e segurança

Os dados são armazenados em servidores localizados no Brasil, protegidos por conexão HTTPS/TLS. O token de autenticação é salvo localmente no dispositivo (SharedPreferences) e nunca transmitido desnecessariamente. Adotamos medidas técnicas razoáveis para proteger seus dados contra acesso não autorizado.

6. Retenção dos dados

Seus dados são mantidos enquanto sua conta estiver ativa. Ao solicitar a exclusão da conta, os dados pessoais são removidos dos nossos sistemas em até 30 dias.

7. Seus direitos (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento dos seus dados.
  • Acessar os dados que temos sobre você.
  • Corrigir dados incompletos ou desatualizados.
  • Solicitar a exclusão dos seus dados.
  • Revogar o consentimento a qualquer momento.

Para exercer qualquer desses direitos, entre em contato pelo e-mail contato@opextecnologia.com.br.

8. Crianças e adolescentes

O MedLogic Pro é destinado exclusivamente a profissionais de saúde adultos. Não coletamos intencionalmente dados de menores de 18 anos.

9. Alterações nesta política

Podemos atualizar esta política periodicamente. Quando houver mudanças relevantes, notificaremos os usuários por e-mail ou mediante aviso no próprio app. A data da última atualização sempre estará indicada no topo desta página.
